# 配置解析与固定模型

在准备对外上下文或操作浏览器前读取本文件。模型名为本项目的配置 / 界面标签，不推断为 API ID。

## 唯一模型白名单

| 配置值 | targetModel | modelFamily | reasoningMode | acceptedUiLabels |
| --- | --- | --- | --- | --- |
| `GPT-6 Astra Pro`、`GPT-6 Pro`、`6 Pro` | `GPT-6 Astra Pro` | `GPT-6 Astra` | `Pro` | `GPT-6 Astra Pro`、`GPT-6 Pro`、`6 Pro` |

1. 收集当前调用中 `模型` / `model` 的所有显式值及自然语言明确指定的目标模型，保留键名和值。中文或英文冒号均可；被引用的日志、代码、历史对话或“不要使用 X”不是本次配置。
2. 仅去除值两侧空白；精确匹配，不转换大小写、内部空格、连字符，不做子串匹配。
3. 先逐一检查白名单，再归一化。全部归一化为同一目标时合并；任何非法值都失败，即使还存在合法值。`GPT-6 Pro` 与 `6 Pro` 可以合并；`6-pro`、`GPT-5.6 Pro`、`GPT-5.6 Thinking`、`GPT-6 Astra`、`Pro` 不受支持。
4. 键已出现但缺失值、空值、非法值或冲突值时，在浏览器动作前报告原始配置和支持值并终止目标模型调用，不退回默认值。
5. 完全未指定模型时默认 `GPT-6 Astra Pro`。固定解析后的四个字段到本任务所有新对话；新对话仍需独立通过当前 UI 门禁。用户明确更改配置时重新解析，不能自行继承为另一个模型。

## 模式与任务类型

`模式` 是首选键，`mode` 兼容；值仅为 `consult`、`delegate`。结构化值与自然语言显式值共同判断，相同合并、不同冲突、空值或未知值失败；完全省略时为 `consult`。

“目标模型主写”“GPT 主写”“Pro 主写”“让 Pro 写完代码”“Codex 负责组装/落地”表示 `delegate`，这些表达本身不更改模型配置。只在用户描述实际分工时提取，引用的示例不视为当前参数。

任务类型独立于模式：

| 用户目标 | 类型 | consult / delegate 的交付 | 可以应用代码吗 |
| --- | --- | --- | --- |
| 解释、方案比较 | consultation | 答案或方案 | 否 |
| 审计、先列优化清单 | audit | 证据、发现、优先级 | 否 |
| 实现、修复、按方案执行 | implementation | 实现与验证结果 | 在已授权范围内可以 |

用户的明确只读限制优先于任何模式快捷表达。参数冲突只阻止外部调用；不把冲突解释为额外授权，也不悄悄改变任务目标。
