# 最终报告

面向用户报告结果与真实验证，正常成功优先不超过 8 条。门禁标签、位置、检查时点、原始配置、请求 / 回复对应关系、源码和交付哈希等完整证据保存在已有任务记录；只有解释结果需要时才在最终回复展开。

## 未触发外部咨询

- 完成了什么，或只读审阅发现了什么。
- 实际验证及结果。
- `consult` 未触发外部咨询的原因。
- 必要限制和 Git 状态。

不填写不存在的对话链接、门禁失败或归档哈希。

## 协作成功

- 实际结果与修改范围；审计则报告发现与优先级。
- 协作模式、目标模型、基于当前已选 UI 的门禁结果；对话链接只给一次。
- 采纳 / 修正的关键建议，以及 Codex 完成的接入审查。
- 本地实际运行的验证、未验证风险和 Git 状态。

目标模型声称的测试不计为本地已运行结果；ZIP / diff 详细清单不重复粘贴。

## 外部调用失败

- 明确当前失败类型：能力缺失、认证等待、配置错误、模型门禁、发送结果未知或交付不完整。
- 门禁失败使用 `目标模型调用失败：未通过 <targetModel> 模型门禁。`，说明期望与最后确认的当前 UI 证据。
- 说明已经完成的独立本地工作、是否有原对话可恢复、剩余依赖。
- 用户要求的外部评审或委托未完成时，不能将任务整体标为已完成；已保留的有效本地修改也不自动撤销。

只请求解除实际阻塞所需的最小操作，不要求重复授权同一范围。
